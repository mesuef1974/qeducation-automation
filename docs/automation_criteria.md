# معايير الأتمتة: خطوة خطوة

بقرار المعلم في 2026-11-04، بعد مناقشة كل خطوة في رسم الأتمتة. لكل خطوة: شرط البدء، ومعيار النجاح، وشرط التوقف، والتوقيت.
الحالة: **قرارات معتمدة، لم تُطبَّق في الكود بعد** (خطة التطبيق في آخر الملف).

## 0. المنصة والجلسة

| النوع | المعيار |
|---|---|
| الدخول | آلي دون أي كلمة مرور مخزّنة: إن انتهت الجلسة يُعاد الدخول بصمت من جلسة الحساب المحفوظة في ملف المتصفح الخاص بالأتمتة |
| الفحص | عند تشغيل الجهاز وكل صباح، قبل أي مهمة مجدولة |
| إن تعذّر الدخول الصامت | تنبيه ويندوز فوري بزر يفتح نافذة الدخول، والدورة تنتظر ثم تكمل وحدها بعد دخولك |
| ثابت | لا كلمات مرور ولا ملفات جلسة في المستودع؛ قراءة فقط ما لم تكن الخطوة ٥ |

## 1. المزامنة (قراءة فقط)

| النوع | المعيار |
|---|---|
| شرط البدء | جلسة سارية، والصف مفعّل ومربوط بخطة |
| النجاح | كل درس له معرّف وعنوان وموضع، بلا تكرار في الموضع |
| الانكماش | **أي نقص** في عدد الدروس عن المحفوظ يوقف المزامنة ولا يحفظ شيئًا، وينبّه المعلم؛ الحذف المقصود يؤكّده المعلم مرة واحدة |
| المطابقة | **100% لما سيُكتب عليه**: الدرس غير المطابق للخطة يُستبعد من كل اقتراح وكتابة وينبَّه عليه، والباقي يكمل |
| الحداثة | لا كتابة على المنصة على مزامنة أقدم من **ساعة**، ويُقرأ الدرس نفسه مباشرة قبل الكتابة عليه |
| الحمل | ثانية على الأقل بين الطلبات (3–6 ث في الحزمة)، وإعادة بعد 429 |

## 2. تدقيق الجودة (قراءة فقط)

| النوع | المعيار |
|---|---|
| الوصف | **120 حرفًا على الأقل ويذكر هدف الدرس** (ما سيتعلمه الطالب) |
| الأقسام | **بنية: تهيئة + شرح (عرض أو فيديو أو تفاعلي) + تقييم** |
| التقييم | **ذاتي التصحيح، 5 أسئلة فأكثر، مرتبط بنتاج الدرس** |
| الصورة والنتاج | صورة من المحتوى لا الافتراضية، ونتاج مربوط |
| الهدف | **دروس الأسبوعين القادمين مكتملة 100%**، وما لم يكتمل ينبَّه في «اليوم»؛ والباقي نسبة للمتابعة |

## 3. الاقتراح (لا كتابة)

| النوع | المعيار |
|---|---|
| خارج أسبوع الخطة | يُقترح بتنبيه ومقدار الانحراف وسببه، **ولا يُعتمد آليًا أبدًا** |
| التاريخ الماضي | **للمراجعة فقط** بخيارين: تاريخه أو أقرب حصة قادمة؛ لا اعتماد آلي |
| نافذة التقييم | يُفتح 7:00 يوم الدرس، ويُستحق بعد يومين 23:59، **والتأخير مسموح ومرصود** (الخطوة ٦) |
| المحتوى | لا يُعرض اقتراح محتوى إلا إذا **اجتاز معايير الخطوة ٢** |

## 4. اعتماد المعلم (البوابة البشرية)

| النوع | المعيار |
|---|---|
| الاعتماد الآلي | الروتيني السليم فقط: تواريخ وإسناد ونشر **بلا أي تنبيه ومطابقة 100%** ضمن 14 يومًا؛ المحتوى يدوي دائمًا |
| الصلاحية | يسقط الاعتماد **بعد 48 ساعة** أو **إن تغيّر الدرس على المنصة** بعده، ويعود للمراجعة |
| الأدلة | كل اقتراح يُعرض بـ **قبل/بعد + السبب من الخطة + الأثر على الطالب** |
| التذكير | اقتراح لدرس يبدأ خلال **48 ساعة** يظهر أعلى «اليوم» بلون الخطر |

## 5. التطبيق (الكتابة الوحيدة على المنصة)

| النوع | المعيار |
|---|---|
| ثابت | إضافة فقط: لا تعديل لموجود ولا حذف؛ قراءة الدرس قبل كل إضافة؛ فحص شكل المنصة قبل الكتابة |
| الفشل | **يتوقف عند أول خطأ غير متوقع**؛ التخطي المعروف (موجود مسبقًا) لا يوقف |
| التجربة | **العنصر الأول ثم تحقق آلي منه ثم البقية**؛ إن لم يصح يتوقف |
| الإثبات | **قراءة بعدية لكل عنصر**: لا يُعدّ «مطبّقًا» إلا إذا طابقت القراءة القيمة المعتمدة |
| التوقيت | في أي وقت |

## 6. التحقق من منظور الطالب (قراءة فقط)

| النوع | المعيار |
|---|---|
| العمق | لدروس اليوم والغد: **الظهور + الأقسام ظاهرة + التقييم متاح بمواعيده** |
| التوقيت | **كل يوم دراسي 6:30** (أو فور تشغيل الجهاز إن كان مطفأً) **+ بعد كل تطبيق** |
| المخفي الظاهر | درس مخفي يراه الطالب **يُفشل التحقق** وينبّه |
| التأخّر | **أعداد فقط بلا أسماء**: من سلّم في الموعد ومن تأخر لكل تقييم |

## 7. بطاقة الأداء

| المعيار | الهدف والقياس |
|---|---|
| وقت المعلم | **قياس فعلي أسبوعًا واحدًا** بدل التقدير، وزمن المهام المؤتمتة من البث الحي |
| الموثوقية | **99% من العمليات تكتمل + صفر كتابة خاطئة** (التوقف الآمن ليس خطأ) |
| تفاعل الطالب | **نسبة من فتح درس اليوم وأنجزه وسلّم تقييمه**، أرقام بلا أسماء ومحلية، الهدف 80% |
| جودة المحتوى | تتبع تعريف الخطوة ٢ |
| الهبوط | **تنبيه إذا بقي معيار تحت هدفه يومين متتاليين**، مع السبب والخطوة التالية |

## 8. حزمة التحضير الأسبوعية (قراءة فقط، إلى سطح المكتب)

| النوع | المعيار |
|---|---|
| ثابت | الدروس من الخطة؛ يتوقف إن لم يساوِ عددها عدد الحصص؛ تشغيل ثانٍ مطابق؛ لا سنة قديمة (فحص Word) |
| النواقص | **تكتمل وتُعلَّم «غير جاهزة»** مع ملف «النواقص»، حتى تُستكمل أو يعفي منها المعلم |
| المرجع | **الخطة**، وفرق تواريخ المنصة يُقترح تصحيحه في الخطوة ٣ |
| التوقيت | **آليًا يوم الاثنين للأسبوع التالي** (ضمن الدورة) |
| بعد دليل المعلم | **كل هدف ونتاج في الدليل يظهر في التحضير، وله شريحة في العرض، وسؤال في ورقة العمل أو التقييم**؛ جدول تغطية مرفق |

## 9. الدورة الأسبوعية

| النوع | المعيار |
|---|---|
| الموعد | **الاثنين 7:00** مع تشغيل الجهاز في المدرسة، وكل شيء جاهز **قبل 8:00** للأسبوع القادم |
| الترتيب | التواريخ ← الإسناد ← النشر ← التحقق ← حزمتا الصفين والرسالة ← لقطة بطاقة الأداء |
| الحد | **عدد حصص الصف في نافذة الـ14 يومًا** لكل صف ومرحلة؛ ما زاد لا يُعتمد منه شيء |
| الإيقاف الآلي | **كتابة خاطئة واحدة أو تحققان فاشلان متتاليان** يعطّلان الدورة حتى يعيد المعلم تفعيلها |
| التقرير | **تنبيه ويندوز احترافي + ملخص ثابت أعلى «اليوم»** حتى يُقرأ؛ لا كتابة على منصة قطر |
